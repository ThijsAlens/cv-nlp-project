# nlp_testing

RAG-backed waste disposal chatbot. Uses FAISS (semantic search) and BM25
(keyword search) to retrieve relevant Belgian waste disposal rules, then
passes them as context to a locally running Ollama LLM.

## Quick start

```bash
# Install dependencies
uv sync

# Build the FAISS index (once, or after changing documents/general/)
uv run python scripts/run_build_index.py

# Start Ollama and pull the configured model
ollama serve            # in a separate terminal
ollama pull granite4.1:3b

# Run the chatbot
uv run python scripts/run_chat.py
```

## Chatbot commands

| Input | What happens |
|-------|-------------|
| `start` | Generates an opening disposal instruction. Items are read from `config/test_input.json` or prompted interactively. |
| Any question | Answers using RAG context and the current conversation history. |
| `quit` | Exits the chatbot. |

## Project layout

```
config/         User-editable YAML, prompt templates, sorting rules, test input
documents/
  general/      Belgian waste rule documents indexed by FAISS
  regions/      Region/city-specific rule documents searched by BM25
faiss_index/    Auto-generated by run_build_index.py (not tracked by git)
src/
  nlp_assistant/
    rag_system.py   RAGSystem class (FAISS + BM25)
    chatbot.py      WasteAssistant class (LLM chat logic)
    utils/          Shared I/O helpers
scripts/        Runner entry points
```

## Configuration

Edit `config/nlp_config.yaml` to change the LLM model, embedding model,
document paths, and debug flag. See `config/README.md` for details on each setting.

## Adding documents

- **General rules** (for FAISS): add `.txt` files to `documents/general/`, then
  rebuild the index: `uv run python scripts/run_build_index.py`.
- **Region rules** (for BM25): add `.txt` files to `documents/regions/`.
  The BM25 index is rebuilt automatically at startup -- no rebuild needed.

## Debug mode

Set `debug: true` in `config/nlp_config.yaml` to print retrieved chunks and
the extracted location to the console on each chat turn.
