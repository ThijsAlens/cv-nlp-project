# demo

Smart Waste Sorter demo. Points a webcam at an object, detects the material
with YOLO, and answers disposal questions via a RAG-backed chatbot.

## Prerequisites

- A webcam connected to the machine.
- Ollama running locally: `ollama serve` (separate terminal).
- The configured Ollama model pulled: `ollama pull granite4.1:3b`.
- A trained model bundle placed in `models/` (see `models/README.md`).

## Quick start

```bash
# 1. Install dependencies
uv sync

# 2. Copy your trained model bundle into models/
#    (bundle must contain weights/best.pt)

# 3. Build the FAISS index for the NLP chatbot (once)
uv run python build_nlp_index.py

# 4. Start Ollama in a separate terminal
ollama serve
ollama pull granite4.1:3b

# 5. Run the demo
uv run python demo.py
```

Press **ESC** to stop.

## Demo commands (in the terminal)

| Input | What happens |
|-------|-------------|
| `start` | Reads the latest YOLO detections and generates a disposal instruction. |
| Any question | Answers using RAG context and the conversation history. |
| **ESC** | Stops both threads and exits the program. |

## Configuration

Edit `config/demo_config.yaml` to change the model bundle, LLM model, or paths.
No Python code needs to change.

## Project layout

```
config/           demo_config.yaml and README
models/           Trained model bundles (weights/best.pt)
nlp/              RAG system, chatbot, and NLP thread runner
  documents/
    general/      Belgian waste rule documents (FAISS)
    regions/      Region-specific rule documents (BM25)
  faiss_index/    Auto-generated by build_nlp_index.py
vision/           Webcam capture and YOLO inference
temp/             Temporary files shared between threads (auto-created)
demo.py           Main entry point
build_nlp_index.py  One-time FAISS index builder
```

## Updating the NLP module

The core NLP files (`nlp/rag_system.py`, `nlp/chatbot.py`, `nlp/utils/io.py`)
are kept identical to `clean_project/nlp_testing/`. After making changes in
`nlp_testing`, copy the updated files here. See `nlp/README.md` for details.
